# Markdown Cheat Sheet

## Heading (หัวข้อ)

### วิธีเขียน

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
```

### ผลลัพธ์

# Heading 1
## Heading 2
### Heading 3

---

## Paragraph (ย่อหน้า)

### วิธีเขียน

```markdown
บรรทัดแรก

บรรทัดใหม่ (เว้นบรรทัด 1 ครั้ง)
```

### ผลลัพธ์

บรรทัดแรก

บรรทัดใหม่

---

## Line Break (ขึ้นบรรทัดใหม่)

### วิธีเขียน

```markdown
บรรทัดแรก  
บรรทัดที่สอง
```

---

## Bold (ตัวหนา)

### วิธีเขียน

```markdown
**ข้อความตัวหนา**
```

### ผลลัพธ์

**ข้อความตัวหนา**

---

## Italic (ตัวเอียง)

### วิธีเขียน

```markdown
*ข้อความตัวเอียง*
```

### ผลลัพธ์

*ข้อความตัวเอียง*

---

## Bold + Italic

### วิธีเขียน

```markdown
***ข้อความหนาเอียง***
```

### ผลลัพธ์

***ข้อความหนาเอียง***

---

## Blockquote (คำพูด)

### วิธีเขียน

```markdown
> This is a quote.
```

### ผลลัพธ์

> This is a quote.

---

## Ordered List (ลำดับเลข)

### วิธีเขียน

```markdown
1. Item One
2. Item Two
3. Item Three
```

### ผลลัพธ์

1. Item One
2. Item Two
3. Item Three

---

### ผลลัพธ์

## Unordered List (Bullet)

### วิธีเขียน

```markdown
- Apple
- Orange
- Banana
```

### ผลลัพธ์

- Apple
- Orange
- Banana

---

## Nested List (รายการย่อย)

### วิธีเขียน

```markdown
- Fruit
  - Apple
  - Orange
```

### ผลลัพธ์

- Fruit
  - Apple
  - Orange

---

## Code

### วิธีเขียน

```
`print("Hello")`
```


### ผลลัพธ์

`print("Hello")`

---

## Code Block

### วิธีเขียน

````markdown
```python
def hello_world():
    print("Hello, World!")
```
````

### ผลลัพธ์
```python
def hello_world():
    print("Hello, World!")
```
