## Markdown คืออะไร

markdown คือภาษาสำหรับจัดรูปแบบข้อความ ที่ถูกทำให้คนที่เขียน HTML ไม่เก่ง สามารถเขียน HTML ได้ โดยใช้ สัญลักษณ์ แทนการใช้ tag ต่างๆใน HTML

## คำสั่งเบื้องต้น

- หัวข้อ (Heading): ใช้เครื่องหมาย # เช่น # หัวข้อใหญ่
- ตัวหนา (Bold): ครอบข้อความด้วยเครื่องหมายดอกจันคู่ เช่น **ข้อความหนา**
- ตัวเอียง (Italic): ครอบข้อความด้วยเครื่องหมายดอกจันเดี่ยว เช่น *ข้อความเอียง*
- รายการ (List): ใช้เครื่องหมาย - หรือ *

ง่ายกว่าเขียน HTML เยอะ เมื่อก่อน อยากได้เว็บเพื่อจะลงรูปหรืออัพเดท บลอก ต้องมีการต่อฐานข้อมูลเพื่อให้ง่ายต่อการทำเว็บ แต่หลังจากมี markdown ชีวิตก็ง่ายขึ้นเยอะเลย ตอนนี้ อยากวางรูปในหน้าเพจก็แค่เอารูปอัพลง แล้วก็ไปใช้ markdown แนบรูปก็จบแล้ว
